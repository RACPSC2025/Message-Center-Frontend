# Modulos Colsubsidio - Documentacion de Contexto para IA

Este directorio centraliza la documentacion funcional y de configuracion de los nuevos modulos para Message Center.

Objetivo:
- Proveer contexto suficiente para que un modelo de IA comprenda cada modulo.
- Establecer vocabulario comun, reglas de negocio y flujos esperados.
- Preparar la fase posterior de definicion e integracion de APIs.
