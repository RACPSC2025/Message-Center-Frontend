# Stack tecnologico

## Frontend principal

- React 18 (SPA)
- React Router v6 con HashRouter
- Redux Toolkit para estado global
- Material UI v5 como libreria de componentes
- Tailwind CSS para utilidades de estilo

## Datos y red

- Axios para integracion REST
- Apollo Client configurado (uso actual minimo)
- runtimeConfig para leer API URL sin recompilar

## Internacionalizacion

- i18next + react-i18next
- Idiomas principales: es, en
- dayjs sincronizado con idioma desde language provider

## Librerias relevantes

- react-toastify (toasts)
- chart.js / react-chartjs-2 / echarts (graficas)
- fullcalendar (calendario)
- ag-grid (tablas)
- lexical (editor enriquecido)
- react-pdf-viewer + pdfjs-dist
